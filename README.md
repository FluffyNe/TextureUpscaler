
## TextureUpscaler MMD贴图超分工具~

## 一、使用方法

### 方式 1：把图片拖拽到 exe

把图片或整个文件夹直接拖到 `TextureUpscaler.exe` 上，跑完弹窗会提示"全部完成"，回车关闭页面
结果生成在图片旁边的 `upscaled` 文件夹里

### 方式 2：Web界面

双击 `启动Web界面.bat`，浏览器自动打开 `http://127.0.0.1:5000`
使用web端时不要关闭黑色的界面喔~

## 二、Web 界面能干什么

### 1. 普通图片超分

- 把图片拖到中间，或点一下选择文件
- 右侧可以调：红绿蓝、对比度、亮度、饱和度、锐化（预览实时刷新，双击数值可直接输入）
- 选模型和倍率
- 点「超分生成」
- 完成后可以**下载新文件**，也可以**直接替换原图**（"替换原图"模式）

### 2. 模型贴图超分（左侧模型预览）⭐

1. 点「模型预览」展开左栏 →「导入 PMX / PMD 模型」
   - 模型和贴图一起多选导入，或者**直接把整个模型文件夹拖进页面**
2. 在预览区看模型：左键/右键拖动旋转，滚轮缩放，中键平移
3. 最左边「贴图」栏列出这个模型用到的所有贴图
   - 把某张贴图**拖到中间区域** → 自动进入超分流程
   - 超分完成后自动把结果**挂回模型**上，当场看效果（挂载过的贴图会有标记）
4. 不满意就换倍率再超分一次，满意了就…看下面第 4 条吧~

### 3. 材质与灯光

- **材质面板**（预览区下方），点开可以选中某个材质，可以选择隐藏，在材质栏中选中的材质的相应贴图在左侧贴图区会有高亮提示
- 或者是**直接点击模型**也能选中对应材质
- 预览区**左下角光照**：可以调全局亮度/环境光/主光/补光，不用怕浴霸咧~

### 4. 一键导出

挂载完超分贴图后，点「导出模型与贴图 (zip)」：
zip 直接存到 `web/export` 文件夹，并自动弹出文件夹选中它
压缩包 = 模型文件 + 全部贴图

> 并非通过浏览器下载，因为好多人包括我都有用IDM这个工具，可能会导致无法正常下载www

### 5. 渲染贴图页（PBR）

主界面右上「渲染贴图」进单独页面：从一张图生成法线/高度/粗糙度/金属度/AO 一套 PBR 贴图，每张可单独预览下载

## 三、常见问题

**超分很慢？**
原图越大越慢，耐心等喔~

**端口被占了？**
改 `web/app.py` 最后一行 `port=5000` 换个端口

**模型导不进去？**
模型引用了没导入的贴图 → 重新整包拖入模型文件夹

**拖贴图到中间没反应？**
看页面顶部有没有提示条：
- 「已发送到超分区」→ 说明上传成功咧
- 红字「没有该贴图的本地文件记录」→ 重新导入一次模型

**浏览器缓存旧页面？**
按 Ctrl+F5 强制刷新

## 四、环境要求

- Windows 10/11（x64）
- 任意支持 Vulkan 的显卡（核显也能跑）
- 不需要装 Python / 不需要联网

## 五、源码跑法（可选）

装了 Python 的话也可以不双击 bat：

```bash
pip install -r web/requirements.txt
python web/app.py
```
